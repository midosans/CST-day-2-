About the course

Client-Side Technologies is a hands-on course for web developers at our training centre in Cairo. You will build real web pages from the very first day.

Chemists write H2O and mathematicians write 210; web developers learn that a div is the right choice inside a sentence.

Glossary

Tag
a keyword inside angle brackets such as <p>
Attribute
extra information inside a start tag
Element
a start tag, its content and its end tag
Entity
a code such as &copy; that shows a special character
